# ARA Base artifact

先读 `project.yaml` 与 Issue 概览；详细记录使用命令按需提取。

- `issues/issueNNN.yaml`：独立维护的 Issue DAG、研究总结和两组重点 idea。
- `issues/issueNNN.md`：公共条件与各 idea 的详细纪要。
- `trace/ideas.yaml`：仅记录前置依赖的 idea DAG。
- `trace/sessions/*.yaml`：观察形成结论及后续修订的追加事件。
- `logic/claims.yaml`：当前主张、适用范围和证据状态。
- `staging/observations.yaml`：保留原始观察与成熟条件。
- `evidence/index.yaml`：可定位和校验的证据。
- `views/index.html`：自动生成的离线双层地图。

空项目只包含虚拟根。没有研究事实时不创建虚假的 idea 或推荐列表。
